Chairside Compare 0.7.4 — Windows x64 portable edition

使用方法
1. 将整个 ChairsideCompare 文件夹复制到另一台 Windows 10/11 64 位电脑。
2. 双击 ChairsideCompare.exe。无需安装 Python，也不需要联网下载运行库。
3. 必须保留同目录的 _internal 文件夹，不能只复制 EXE。
4. 拖入两个或多个模型，或点击“导入模型”。模型单位为毫米；新拖入文件按顺序追加。
5. 在“模型与偏差”中选择参考和比较模型，开始配准。各模型独立对齐参考，不串联各轮变换。
6. 整体显示区右上角按导入顺序显示各模型的不透明度；悬停查看文件名。彩虹图和偏差测量只对应所选一对模型。
7. “拖线创建剖面”后左键拖线，松开生成。剖面经过直线并沿当前观察方向延伸；Esc 取消。
8. “清除当前剖面”恢复绘制前的截面位置、方向和缩放。保存病例会保留自定义剖面和恢复信息。
9. 切换比较模型会清除旧模型对的测量；右下角 Henry Van · GitHub 可打开项目仓库。

编辑剖面
Alt＋左键拖动：平移 3D 剖切平面。
拖动边界：改变这一侧长度，对边固定，维持长方形。
拖动角点：以经过矩形中心的自身法向为轴旋转，保持剖切方向不变。边缘仅显示橙色轮廓。边接近侧视时先旋转观察角度再拉伸。
平移、旋转、边界尺寸随病例保存；清除当前剖面恢复编辑前状态。
截面浏览、距离测量、角度测量为同排互斥按钮。
透明度面板固定在整体显示区右上角，不跟随 3D 大小视图交换或缩小；已移除通用查看器入口。

界面精简
剖面按钮依次为：拖线创建剖面、按当前 3D 视角设截面、清除当前剖面。
取消截面范围输入、聚焦治疗区域、交换大小画面按钮及滚轮步长调整。
截面滚轮步长固定 0.05 mm，打开旧病例同样生效；双击小窗仍可交换大小视图。

数据位置
病例、设置保存到 %LOCALAPPDATA%\ChairsideCompare（当前 Windows 用户）。
每轮模型保存到该目录的 imports 子目录，同名导出被覆盖不会改变已导入副本。
程序文件夹可以移动；用户数据不会因移动程序而丢失。
打开既有病例时选择包含 geometry.npz 的病例文件夹内的 case.json。
跨电脑继续追加扫描和重新配准时，请一并备份 imports，并在导入窗口更新路径。
包内不含患者数据。卸载时删除程序文件夹即可；病例数据需单独备份/管理。

兼容性
本版本面向 Windows x64，包含 Python 3.12、Qt、VTK、Open3D 和配准算法。
显卡驱动和远程桌面环境会影响三维渲染；请在目标电脑验证导入、配准与显示。
未作代码签名，Windows 可能显示未知发布者提示。
不能把本机打包测试等同于目标电脑或临床精度验证。
