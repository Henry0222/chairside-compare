# Chairside Compare · 椅旁预备对比

面向固定修复预备复核和多轮口扫对比：导入多个模型，独立配准至共同参考，在三维叠加与截面视图中观察所选模型之间的表面差异。

**版本：0.7.4 · Windows x64 · Python 3.12 · 配准核心 3.0.0**

## 主要功能

- **多模型工作流**：支持两个或多个模型，按导入顺序追加，可在导入窗口移除。配准时各模型独立对齐所选参考；参考不变且文件哈希匹配时复用已有配准。
- **独立导入副本**：每次导入保存模型副本，防止口扫软件覆盖同名文件后改变已有轮次。
- **拖入即预览**：支持 STL / PLY，可从资源管理器拖到导入框或三维视图；未配准时显示原始位置。
- **明确的比较对象**：选择参考模型和比较模型；彩虹图显示在参考模型上，偏差点选针对比较模型。多模型同时显示，但每次偏差只对应选定的一对模型。切换比较对象清除旧测量。
- **视图内不透明度**：整体显示区右上角按导入顺序显示固定宽度滑块；悬停显示模型文件名，0% 隐藏，100% 不透明。参数随病例保存。
- **三维与截面联动**：平行投影，左下角截面小窗可双击与主视图交换；截面平面为橙色，不透明度可调。
- **拖线剖面**：剖面按钮依次为“拖线创建剖面”“按当前 3D 视角设截面”“清除当前剖面”。点击“拖线创建剖面”，在 3D 视图左键拖线；剖面经过这条线并沿当前观察方向延伸。松开后退出绘制，Esc 取消，过短线段不生成剖面。清除后恢复绘制前的截面位置、方向、偏移与缩放；重复绘制仍保留最初的恢复位置。
- **编辑 3D 剖面**：Alt＋左键拖动平移；拖动边界仅改变该边、固定对边；拖动角点绕自身法向旋转，保持剖切方向不变，始终保持长方形。剖面范围同步裁剪截面曲线。边缘仅显示橙色轮廓；边角手柄在定位/偏差测量开启时仍可使用。边接近侧视时请先转动视角。透明度控件固定在整体显示区右上角，不随 3D 大小视图交换位置或缩小。
- **局部偏差测量**：默认半径 0.1 mm，只显示面积加权平均偏差，文字不被模型遮挡。
- **截面测量**：距离测量及有向角度测量；支持重复点选修正截面中心。
- **病例保存**：记录配准矩阵、诊断、显示参数、测量与视角；每轮扫描独立保存。
- **配准诊断**：可读摘要展示状态、重叠率、表面残差、耗时和方案选择原因，亦可切换原始诊断。

## 使用流程

1. 在其他软件中生成目标预备体模型。推荐包含邻牙的全牙列数据，单位为毫米。
2. 导入两个或多个模型，在“模型与偏差”选择参考与比较模型。后续扫描继续追加，不覆盖之前的模型。
3. 点击“开始配准”，所有模型独立对齐参考；查看结果与诊断，复核共同牙面的对齐情况。
4. 调整模型透明度和彩虹色标；点击模型定位截面中心，可连续重选，再次点击定位按钮退出。
5. 使用拖线剖面、三维平均偏差、截面距离或角度测量复核形态；保存视图，或导入下一轮扫描后再次配准。

右下角署名链接可打开本项目 GitHub 仓库。旧版双模型、三模型病例仍可打开；保存的显示参数、测量和视角继续支持恢复。

## 鼠标操作

| 操作 | 三维视图 | 截面视图 |
| --- | --- | --- |
| 左键拖动 | 旋转模型 | 旋转截面方向 |
| 中键拖动 | 平移 | 平移 |
| 右键拖动 | 缩放 | 缩放 |
| 滚轮 | 缩放 | 移动截面 |
| Ctrl + 滚轮 | 缩放 | 缩放 |
| 双击小窗 | 交换大小视图 | 交换大小视图 |

滚轮经过侧栏参数框时滚动侧栏，不修改参数。截面初始范围为 10 mm；旧病例恢复其保存值，后续直接拖动边框调整，不再显示范围输入框。截面滚轮步长固定为 0.05 mm，打开旧病例也采用此步长。聚焦区域和交换大小画面按钮已移除；仍可双击小窗交换。

角度测量中，点 1→2 定义参考方向，点 3→4 定义待测方向。按截面画面从参考转向待测，逆时针为正、顺时针为负，范围为 −180° 至 +180°。取点方向应保持一致；正负表示转向，不自动判定倒凹。

## 从源码运行

仓库包含椅旁应用及配准核心。建议使用 Windows x64 和 Python 3.12。

在仓库根目录运行：

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -e ./general_model_registration -e ./chairside_compare
.venv\Scripts\python.exe chairside_compare/run.py
```

完成依赖安装后，也可双击根目录 `run_app.bat`。

主要依赖：PySide6、VTK、Open3D、NumPy、SciPy。具体版本约束见两个子项目的 `pyproject.toml`。

## 数据与目录

```text
chairside_compare/              椅旁应用、测试、打包脚本
  src/chairside_compare/        界面、几何计算、存储与诊断
  scripts/                     回归与查看器辅助脚本
  packaging/                   PyInstaller 配置与第三方许可
  tests/                       核心测试
general_model_registration/    配准核心 3.0.0
run_app.bat                     源码启动入口
```

- 免安装版：病例和设置存入 `%LOCALAPPDATA%\ChairsideCompare`。
- 源码版：数据存入 `chairside_compare/cases`，默认显示设置存入 `.user/display.json`。
- 一个病例包含 `case.json` 和 `geometry.npz`；备份或迁移时应复制完整病例文件夹。
- 导入原始副本位于数据目录的 `imports` 下。迁移后若还要追加扫描并重新配准，应一并备份这些副本，并在导入窗口更新其路径；仅浏览已保存几何和切换偏差对象不依赖原始 STL 文件。
- 仓库不包含患者模型、病例、真实病例截图、密钥、虚拟环境或构建缓存。二进制包放在 Releases，不放进 Git 历史。

## 当前范围

本版本不自动生成理想预备体，也不提供语义牙齿分割或自动牙位编号。自动变化区只用于定位提示。

彩虹图将当前表面的有符号偏差插值映射到目标表面，不能直接解释为车针进给深度。无效对应显示灰色；配准失败时禁用偏差显示。表面匹配残差与真实位置误差不同。
